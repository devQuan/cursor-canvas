**Cursor Canvas**  
Last updated: 2026-06-14

## Overview

Cursor Canvas is a VS Code / Cursor extension that renders live previews of your local build output. It operates on your machine and does not collect, transmit, or store personal data on external servers.

## Data we do not collect

- No telemetry or usage analytics
- No crash reports to third parties
- No project file contents uploaded anywhere

## Local storage only

The extension may store on your machine via VS Code workspace state / settings:

- Track override (App / Game / Video) per workspace
- Output folder, port override, and other `cursorCanvas.*` settings

This data does not leave your machine.

## Third-party services

Cursor Canvas does not connect to third-party APIs for core preview functionality.
