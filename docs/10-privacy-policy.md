**Cursor Canvas — Privacy Policy**
Last updated: [DATE]

## Overview
Cursor Canvas is a VS Code / Cursor extension that renders live previews of your local build output. It operates entirely on your local machine and does not collect, transmit, or store any personal data.

## Data We Do Not Collect
- No telemetry
- No usage analytics
- No crash reports sent to external servers
- No personal information of any kind
- No file contents from your projects

## Local Storage
The extension stores the following data locally on your machine using VS Code's workspace state API:
- Your active track override (App / Game / Video) per workspace
- Your configured output folder path
- Your port override setting

This data never leaves your machine.

## Third-Party Services
Cursor Canvas does not connect to any third-party services, APIs, or servers.

## Changes to This Policy
If this policy changes in a future version, the changelog will note it and the new policy will be distributed with the updated extension.
